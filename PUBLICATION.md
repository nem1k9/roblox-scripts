# Codex Hub publication package

Use the same loader for every game listing. It opens the shared key system, validates access and starts the module for the current supported game.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nem1k9/roblox-scripts/main/codexhub.lua"))()
```

Loader URL: https://raw.githubusercontent.com/nem1k9/roblox-scripts/main/codexhub.lua

Get a key: https://jnkie.com/get-key/codexhub

One shared key for all four games. Keys are saved in the executor workspace when file access is supported and validated online on startup. Right Alt toggles the menu on PC; touch devices have an on-screen menu button. Protected game modules are delivered through JNKIE.

## Cold War [VIETNAM]

Title: Codex Hub | Silent Aim, ESP, No Recoil, Fly

Description:

Codex Hub for Cold War Vietnam includes silent aim and mouse aim with configurable FOV, target selection, team and visibility checks, bullet-drop compensation and movement prediction. Visual options include player ESP, names, distance, tracers and limb health.

Weapon controls include no recoil, no spread, full auto and instant equip. Movement and vehicle options include flight, speed, noclip, vehicle boost, traction and instant entry. Includes saved configurations and staff alerts.

Uses the shared Codex Hub key system. Get a key: https://jnkie.com/get-key/codexhub

## Build the Pyramid!

Title: Codex Hub | Auto Farm, Auto Train, Bonus Pool

Description:

Codex Hub automates block farming and delivery to the pyramid, strength training and speed training. It selects available training equipment and uses the completed pyramid's bonus pool when available, including the interval between pyramids.

Includes automatic coin upgrades, code redemption, completion-cutscene skipping and a toggle to reduce Robux purchase prompts. Training and farming modes can be switched from the menu.

Uses the shared Codex Hub key system. Get a key: https://jnkie.com/get-key/codexhub

## Blox Fruits

Title: Codex Hub | Auto Farm, Fruit ESP, Boss Farm

Description:

Codex Hub supports all three seas with automatic sea detection, level-quest farming, material farming, island travel, chest farming and selected stat allocation. Combat supports melee, swords and fruits with M1 attacks, including Kitsune, with configurable hovering and attack settings.

Fruit features include ESP, automatic pickup, fruit-name and rarity filters, storage checks, optional auto-store and Beli gacha rolls. Includes selected boss farming, a living-boss cycle, boss quests, smart Castle and portal routing, Cake Prince and Dough King summon chains, Tyrant of the Skies assistance and submarine travel when unlocked.

Also includes progression-quest assistance, race V2/V3 assistance, an x2 EXP code button and Aura activation after respawn. Character prerequisites still apply; PvP objectives, V4 multiplayer trials and Trevor's valuable-fruit donation require manual completion.

Uses the shared Codex Hub key system. Get a key: https://jnkie.com/get-key/codexhub

## Slayers 2

Title: Codex Hub | Auto Quests, Boss Farm, Breathing

Description:

Codex Hub for Slayers 2 Ouwland includes level-based quest farming, optional boss quests and farming a selected boss without quests. It automatically chooses the nearest Home crystal to the target's spawn area, confirms the new spawn point and continues farming after respawn. Low-health healing flights are disabled.

Breathing features include automatic detection, training-quest assistance, material farming and selectable opening skills. One available selected skill is used close to each enemy before sword attacks; unlocked skills and native cooldowns are respected. Includes skill-tree upgrades and breathing-mastery node purchases when requirements are met.

Other options include faster sword attack handling, optional autoblock, weapon selection, chest opening, nearby loot pickup and safe waiting for boss respawns. Game level, mastery, material and boss requirements still apply.

Uses the shared Codex Hub key system. Get a key: https://jnkie.com/get-key/codexhub
